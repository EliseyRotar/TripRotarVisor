# TripRotarVisor

Sito vetrina statico in HTML e CSS per la promozione turistica di San Pietroburgo,
la "Venezia del Nord".

Progetto scolastico del Gruppo 5, classe 5BI, ITIS Marconi.

## Pagine

- `index.html` - Home
- `attrazioni.html` - Le attrazioni principali
- `ermitage.html` - Museo dell'Ermitage
- `peterhof.html` - Peterhof e i palazzi
- `chiesa.html` - Chiesa del Salvatore sul Sangue Versato
- `eventi.html` - Eventi e feste
- `dormire_e_mangiare.html` - Dove dormire e mangiare
- `contatti.html` - Contatti

## Layout

Logo, menu orizzontale, sottomenu laterale, immagine, descrizione e footer.
L'affiancamento dei contenitori usa solo la proprieta CSS `float`,
le larghezze sono in percentuale e le foto sono libere da Wikimedia Commons.
